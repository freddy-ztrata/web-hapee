Conexão nativa com o Claude via MCP

Hoje a Hapee se torna a primeira plataforma de IA conversacional da América Latina com integração nativa ao Model Context Protocol (MCP) da Anthropic. Seus agentes deixam de chamar o Claude por API: passam a invocá-lo como contexto direto, com menor latência e raciocínio multi-etapa de verdade.

7 Mai 2026 Produto · Tech 4 min de leitura Por Equipe Hapee

Durante o último ano, a pergunta mais recorrente dos clientes Hapee foi sempre a mesma: "por que às vezes o agente parece menos inteligente quando eu passo muita informação do cliente?". A resposta técnica era frustrante: os agentes de IA em plataformas tradicionais cortam o contexto antes de enviá-lo ao modelo, porque cada token custa. Resultado: o modelo não vê toda a conversa, não vê o CRM, não vê o histórico de compras. Perde nuances.

O Model Context Protocol (MCP), que a Anthropic publicou como padrão aberto, resolve isso. Em vez de enviar um prompt fixo, o MCP permite que o Claude peça contexto adicional em tempo real a fontes externas (CRM, base de conhecimento, ferramentas). O raciocínio passa a ser multi-etapa de verdade.

O que muda, em uma linha

Antes: o agente chama o modelo uma vez com um prompt fixo. Agora: o modelo pede os dados de que precisa quando precisa, raciocina, pede mais, decide. Menos latência, respostas melhores.

O que é o MCP Nativo

O MCP Nativo (conexão nativa com o Claude) é a implementação do protocolo da Anthropic dentro dos agentes da Hapee. Quando um agente está configurado em modo MCP, ele expõe automaticamente os seguintes contextos disponíveis ao Claude:

  • o CRM — contato, tags, histórico, etapa do pipeline, valor estimado
  • Conversas — todo o histórico de conversas multicanal desse contato
  • a Base de conhecimento — documentos, FAQs e manuais enviados ao espaço de trabalho
  • Calendários — a disponibilidade real da equipe, não horários simulados
  • Fluxos de trabalho — a capacidade de disparar fluxos a partir da conversa

Como isso aparece na prática

Um exemplo concreto: um cliente que já comprou 3 vezes escreve "oi, preciso de ajuda com meu pedido". Com um agente clássico, o modelo recebe essa frase e um system prompt fixo. Com MCP, o Claude primeiro pergunta ao CRM se esse contato tem pedidos em aberto, vê que há um "em trânsito", vê a data estimada de entrega, vê um ticket anterior que o cliente abriu ontem. E só então responde:

"Oi, Camila! Vi que o seu pedido #4892 sai do estoque hoje e deve chegar amanhã entre 10h e 14h. É por isso que você está escrevendo ou aconteceu mais alguma coisa com o ticket que você abriu ontem sobre o tamanho?" — Resposta gerada com o MCP Nativo

A diferença é que parece humano. Porque tem todo o contexto, não um prompt cortado.

Desempenho · números reais

Depois de 4 semanas em beta com 12 clientes:

  • Latência média: 1,4s (vs 2,8s com a API tradicional)
  • Custo por conversa: −22% (o Claude só pede o contexto de que precisa)
  • Resolução no primeiro contato: +34% (o agente fecha mais casos sem escalar)
  • Qualidade percebida (pesquisa com clientes finais): +41% melhor

Como ativar

Disponível para todos os clientes Hapee a partir de hoje:

  1. Settings → AI Models No seletor de modelo do seu agente, escolha Claude (MCP Nativo) em vez das opções de API tradicionais.
  2. Conecte os contextos Por padrão, a Hapee expõe CRM, Conversas, Base de conhecimento e Calendário. Você pode desativar cada um individualmente se não quiser que o modelo acesse algo.
  3. Teste no sandbox Uma conversa de teste com o seu próprio número. Você vai notar a menor latência imediatamente.
  4. Passe para produção Ative o MCP para todos os agentes de um workspace com um toggle.

O que vem por aí

O MCP Nativo é a primeira de três integrações nativas previstas para este trimestre:

  • OpenAI Assistants API nativa · funções de tool-use com estado persistente
  • Gemini live · sessões de voz multimodais em tempo real
  • Mistral Codestral · agentes que escrevem código de fluxo de trabalho a partir de linguagem natural

Mas o MCP é o mais importante. É o primeiro padrão real da indústria, e a Anthropic o liberou como open source para que qualquer plataforma o adote. Que a Hapee seja a primeira da América Latina a tê-lo nativo não é só marketing: é infraestrutura.
