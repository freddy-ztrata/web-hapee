Lo esencial

Cinco reglas y listo.

La API cubre los mismos objetos con los que trabaja el equipo comercial dentro de Hapee. Todo lo demás sale de estas cinco reglas.

Autenticación

Authorization: Bearer hp_live_…, o hp_test_… en sandbox. Las credenciales las emite la agencia que administra tu cuenta.

Subcuenta

Sale de la credencial. Nunca se manda por parámetro: una credencial solo lee y escribe en su subcuenta.

Formatos

JSON UTF-8, fechas ISO 8601 en UTC, teléfonos E.164, montos como texto decimal con su currency, RUT como 12345678-K.

Listas

Paginación por cursor: limit hasta 100, cursor y next_cursor.

Escrituras

Manda Idempotency-Key en cada escritura: un reintento por un corte de red no duplica nada. Úsalo desde el primer día.

Crea un contacto 2 min

external_id es el id de tu sistema: hace que la carga se pueda repetir sin duplicar. La segunda vez actualiza en lugar de crear, y con la misma Idempotency-Key recibes la misma respuesta con Idempotent-Replay: true.

POST /contacts/upsert

  -H "Authorization: Bearer $HAPEE_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: mi-primera-prueba-001" \

    "external_id": "ERP-DEMO-1",
    "email": "prueba@ejemplo.cl",
    "first_name": "Ana", "last_name": "Pérez",
    "phone": "+56912345678",
    "rut": "12.345.678-5"

Verificar X-Hapee-Signature
const crypto = require("crypto");

function firmaValida(crudo, cabecera, secreto, tolerancia = 300) {
  const p = Object.fromEntries(
    cabecera.split(",").map((x) => x.split("=").map((s) => s.trim())));
  if (!p.t || !p.v1) return false;
  const esperado = crypto.createHmac("sha256", secreto)
    .update(`${p.t}.${crudo}`).digest("hex");
  const a = Buffer.from(esperado), b = Buffer.from(p.v1);
  if (a.length !== b.length || !crypto.timingSafeEqual(a, b)) return false;
  return Math.abs(Date.now() / 1000 - Number(p.t)) <= tolerancia;
}
import hashlib, hmac, time

def firma_valida(cuerpo_crudo: bytes, cabecera: str, secreto: str,
                 tolerancia_seg: int = 300) -> bool:
    partes = dict(
        p.strip().split("=", 1) for p in cabecera.split(",") if "=" in p
    )
    t, v1 = partes.get("t"), partes.get("v1")
    if not t or not v1:
        return False
    esperado = hmac.new(
        secreto.encode("utf-8"),
        t.encode("utf-8") + b"." + cuerpo_crudo,
        hashlib.sha256,
    ).hexdigest()
    if not hmac.compare_digest(esperado, v1):
        return False
    return abs(int(time.time()) - int(t)) <= tolerancia_seg

Errores y versiones

Predecible por diseño.

Una sola forma de error

Todos traen code estable, message, details por campo y request_id. Guarda el X-Request-Id: con él encontramos tu llamada exacta.

v1 es estable

Agregar un campo no rompe: ignora los que no conoces. Un cambio que sí rompa sale como v2, y v1 sigue vivo al menos 12 meses desde el anuncio.

Sandbox y producción, la misma API

Pasar a producción es cambiar la credencial hp_test_ por hp_live_ y la URL del webhook. Nada más. El checklist de salida está en la guía de ERP.
